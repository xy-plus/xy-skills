# 清扫审查对照输入

记录清扫审查改进后仍没发现的问题。下次修改审查问题时，将它们作对照输入：在表中所列功能文字未改的提交上重跑审查，看能否发现这些问题。

| 功能 id | 现文 | 问题 |
|---|---|---|
| `xy-cleanup` | why.text：「现在图不好看，清扫也有很多问题，需要把仓库整理干净。」 | 这是对旧版的抱怨，不是本功能存在的理由。 |
| `render-feature-tree` | why.text：「用户主要用手机看功能图。」 | 只说主要观看设备，没说明出图的必要。 |
| `find-dependencies` | why.text：「功能之间的依赖要不用点就看得出来。」 | 只说希望免点击看出依赖，没说明依赖关系的必要。 |
| `xy-iron-law` | why.text：「出了问题要改根因，不要在别处加东西收拾后果。」 | 只说第一条铁律的理由，未说明另外两条。 |
| `sync-think` | what：「把只有我能定的事做成带建议的选择题，一次问一道。」；why：「AI 自己查得到的事别来打断我；必须我定的事要一次问清，并带上建议。」 | 「一次问一道」和「一次问清」表意冲突。 |
| `workflow-capabilities` | title：「流程用到、也能单独用的本事」；what：「标准工作流程会用到、我也会单独叫来用的三样本事：问我、审查、记账。」 | 运行目录管理也会被流程用且可独立使用，却未归入该分组。 |
