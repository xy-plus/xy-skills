# 清扫审查对照输入

这里记录清扫审查改进后仍没发现的问题。下次修改审查问题时，把它们作为对照输入：在表中所列功能的文字仍未改动的提交上重跑审查，看能否发现这些问题。

| 功能 id | 现在的文字 | 问题 |
|---|---|---|
| `xy-cleanup` | why.text：「现在图不好看，清扫也有很多问题，需要把仓库整理干净。」 | 这是对旧版的抱怨，不是这个功能为什么要有。 |
| `render-feature-tree` | why.text：「用户主要用手机看功能图。」 | 只说了主要观看设备，没有说明为什么需要出图。 |
| `find-dependencies` | why.text：「功能之间的依赖要不用点就看得出来。」 | 只说了希望不用点击就看出来，没有说明为什么需要依赖关系。 |
| `xy-iron-law` | why.text：「出了问题要改根因，不要在别处加东西收拾后果。」 | 只说明了第一条铁律的理由，没覆盖另外两条。 |
